# 💰 Control de Tesorería - Peña

Aplicación web simple y funcional para gestionar las cuotas, gastos y morosos de tu peña.

## ✨ Características

✅ **Dashboard** - Resumen con totales de entradas, salidas y balance
✅ **Gestión de Socios** - Alta y baja de socios
✅ **Control de Entradas** - Registro de cuotas (10€/mes)
✅ **Control de Salidas** - Registro de gastos con descripción
✅ **Reporte de Morosos** - Lista automática con deuda por mes (copiar al portapapeles)
✅ **Cuenta por Socio** - Detalle individual completo de cada socio
✅ **Almacenamiento Local** - Los datos se guardan en el navegador
✅ **Diseño Responsive** - Funciona en móviles, tablets y desktop

## 🚀 Cómo usar

1. Accede a la aplicación desde tu navegador
2. **Gestión de Socios**: Añade o elimina socios en la sección "Socios"
3. **Registra Entradas**: Cada mes, registra la cuota de 10€ por socio
4. **Registra Salidas**: Añade los gastos de la peña
5. **Consulta Morosos**: La app automáticamente detecta quiénes deben dinero
6. **Copia el Informe**: Copia la lista de morosos al portapapeles para enviar al grupo

## 💡 Cómo detecta morosos

La app compara:
- **Debido**: 10€ por mes (cuota fija)
- **Pagado**: Lo que cada socio registró

**Si pagó menos de 10€ = MOROSO**

Ejemplo:
- Juan debe enero (10€) y febrero (10€) = **MOROSO con 20€ de deuda**

## 📱 Acceso

La app está publicada en GitHub Pages y se puede acceder desde cualquier dispositivo con internet. Los datos se guardan localmente en cada navegador.

## 🔐 Privacidad

Todos los datos se guardan **localmente en tu navegador**. No se envía información a ningún servidor externo.
